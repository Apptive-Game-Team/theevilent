# 탑 방어전 유닛과 마법사 설정화

2026-10-30 사용자 요청. towerback, cannonback, lightning towerback, turret, turretback의 개별 설정화와 마법사 여섯 명의 외형 기준을 먼저 만든다. turret은 기존 RockTurret 돌 투석 포탑을 기준으로 한다. Cannonback, Lightning Towerback, Turretback은 사용자 요청에 따른 만화용 장비 조합 시안이며 게임에 구현됐다고 주장하지 않는다.

방어 마법사 세 명은 DEFENDER_TEAL, DEFENDER_PLUM, DEFENDER_OCHRE 작업 ID로 구분한다. 개인 이름·나이·성별·가족사·새 능력은 확정하지 않는다. 색상·머리·얼굴·브로치·지팡이·카드 가방을 반복 작화 기준으로 사용한다.

마법사와 배경의 승인된 만화 비율을 유지하고 설정화는 본문에 가져올 대사가 아니다. 원화 제작을 사용자 최종 승인과 동일시하지 않는다. 선택과 프롬프트는 selected-assets.json 기준이다.
