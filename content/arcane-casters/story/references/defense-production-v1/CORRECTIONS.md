# 작화 검토와 수정 기준

2026-10-30 최신 사용자 지적을 우선한다.

- defender-formation.png와 distant-approach.png의 성벽 밖 방어군은 반려된 구도다. 새 원고 참고로 사용하지 않는다.
- 새 배치는 비전 보병을 닫힌 동문 안쪽, 마법사와 고정 포대를 성벽·보루 위, 이동형 골렘을 넓은 보루와 안뜰 예비대로 둔다. 병력을 성벽 밖 야전에 도열시키지 않는다.
- 작업 크기: 사람1.7m, 성벽10m, 보행면8.5m, 난간1.2m, 정문 개구부7m. Towerback2.6m, Cannonback5m, LightningTowerback5.5m, Turret4m, Turretback4.5m. 이는 그림 비율을 위한 제안이며 게임 수치를 바꾸지 않는다.
- 탑100m 성벽 지름과65m 중앙 탑, 생활관 네 동, 동쪽 정문·서쪽 대피문을 유지한다. 북문·남문을 추가하지 않는다. 기존 건물 시트의 방향과 새 지도의 방향이 다를 때 건물 전체를 회전하며 문을 추가해 맞추지 않는다.
- region-central-scale.png의 탑 주도면과 확대도는 축척·문 위치가 완벽히 맞지 않는 탐색안이다. 정확한 좌표·축척은 scale-layout-guide.png와 SPATIAL-PLAN.md가 기준이며 후속 교정이 필요하다.
- 세계수의 지상 방문 장면은 뿌리 하나가 사람 여러 배 크기이고 줄기 일부만 보이는 구도로 수정한다. 전체 수관을 인물 곁에 작은 보통 나무처럼 넣지 않는다.
- 옛 탑이 나오는 모든 현재 사용 그림과 읽기 화면 자산을 전수 확인해 새 디자인으로 교체한다. 반려 원화의 존재를 수정 완료로 세지 않는다.
