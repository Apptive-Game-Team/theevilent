출발 때 저녁 맥주 약속, 핀만 따라가는 후반, 모크의 붉은 눈과 동굴행,
마지막 “1화 끝” 상자 삭제를 반영했다. 사용자 최종 승인과 공개는 별도다.

built-in imagegen으로 생성·편집했다. 현재 선택본은 art-v6/ 안에 있으며
