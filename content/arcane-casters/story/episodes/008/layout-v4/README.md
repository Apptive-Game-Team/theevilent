# 8화 원근과 시야 확인 자료

`build-layout.py`는 같은 미터 좌표를 원근 투영한다. 원화가 아닌 작화용 구도 자료이며,
완성 이미지의 실측 검증을 대신하지 않는다. 사람 1.7m, 주탑 65m, 외벽 10m,
외벽 구역 지름 100m를 작업값으로 사용한다. 카메라는 `cameras.json`에 기록한다.

- `collapse-wide.png`: 붕괴 순간. 미라는 중앙 기단 동쪽, 동료들은 남서쪽에 있다.
- `crystal-ground.png`: 북쪽 수정 도착 이후. 남쪽 동료들은 카메라 뒤에 있어 보이지 않는다.
- `allies-reverse.png`: 북쪽 수정에서 남쪽을 보는 역방향. 약 50m 떨어진 동료를 작게 잡는다.
- `gate-reverse.png`: 시야 확인 후 사용하지 않은 구도. 북쪽 수정에서 동문은 북동 거주동에 가린다.
  18페이지의 동문은 문 안쪽에 별도 카메라를 두며 미라의 시점으로 연결하지 않는다.

입방체 인물은 높이 확인용이다. 완성 원고의 쓰러진 자세를 뜻하지 않는다.
벽과 탑의 단순 면, 열린 단면, 자료 상단의 치수 글자를 원화에 복사하지 않는다.
