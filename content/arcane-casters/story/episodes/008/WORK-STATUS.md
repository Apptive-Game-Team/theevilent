# 8화 작화와 독자 화면 검토 상태

2026-11-04. 사용자 지적에 따라 18페이지를 art-v4/로 다시 작화했다.
현재 선택본은 selected-pages.json, 열람본은 index.html이다.
사용자 최종 작화 승인은 아직 받지 않았다.

- 초반: 파편에 튕겨 나간 물 궁수를 미라가 끌어내리고, 방금 지나온 자리에 벽체가 떨어진다.
  오린과 동료들은 충격에 발이 밀리며 방어하다 쓰러진다. 대사도 현재 원고에 맞췄다.
- 크기와 시야: 사람 1.7m·주탑 65m·외벽 10m·구역 지름 100m를 같은 좌표에서 투영한
  layout-v4/의 구도 자료를 사용했다. 붕괴는 먼 시점, 근접 인물 컷의 건물은 일부만
  보이게 구성했다. 자료는 완성 작화의 치수를 실측 보증하지 않는다.
- 붕괴 이후: 북쪽 수정까지 기어가는 이동을 남겼다. 남서쪽 동료는 별도 근접 컷이나
  약 50m 거리의 역방향 컷으로 보여준다. 반복되는 수면 자세와 다시 일어선 동료를 수정했다.
- 각성과 요격: 수정 접촉, 불완전한 발사, 마력 집속, 개별 유성 추적과 마지막 격추를 유지한다.
  공격 중 하늘은 연기와 붉은 빛으로 맞췄다. 미라는 상처와 탈진을 유지한다.
- 보존: art-v1/, art-v2/, art-v3-scale/는 이전 시안이다. v3는 사용자 재검토에서 반려됐다.
  art-v4/ 안의 추가 수정 전 파일도 비교용으로 보존한다. 독자 화면에는 선택 목록의 18장만 내보낸다.
- 검증: 선택 PNG 18장 모두 1024×1536·서로 다른 SHA-256 확인. 무손실 WebP와 원본의 픽셀 대응 및
  표지 해시 확인. npm run lint 통과. Playwright 전체 82개 통과(이 과정의 npm run build 포함).
  데스크톱·320px 모바일에서 목록→8화→18장 디코딩·진행 저장·이동·언어 안내를 검사했다.
- 로컬 검토 페이지는 4198 포트에서 제공한다. 휴대용 ZIP은 로컬 전달용으로만 만들고 Git에 포함하지 않는다.
- 기존 PR은 #126을 유지한다. 이전 커밋의 CI 성공은 새 수정본의 CI 결과와 구분한다.
  Vercel에서 이 저장소의 미리보기 프로젝트를 찾지 못했으므로 호스팅 미리보기 검증은 없다.
  앞선 Nginx 런타임 검증은 이전 원고 때의 결과이며 이번 변경에서 라우팅 설정을 바꾸지는 않았다.
- Graphify 실행 파일이 없어 갱신하지 못했다. 운영 머지·배포는 수행하지 않았다.

각성의 영구성, 동료의 생사, 핀의 잠식 해제와 흑막은 확정하지 않는다.
