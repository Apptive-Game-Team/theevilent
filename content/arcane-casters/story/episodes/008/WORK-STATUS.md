# 8화 대본과 작화 검토 상태

2026-11-04 기준. 18/18페이지 작화 및 축척 교정본을 작성했다. 사용자 최종 승인 전 검토본이다.

- [PLAN.md](PLAN.md): 18페이지 대본 초안 작성. 장면별 동작, 인쇄 대사, 공간 연속성, 종료 상태를 포함한다.
- 사용자 승인 설정: 수정 마력 수용에 따른 미라의 각성, 탑 전도와 미라 외 방어 측 전원 전투불능, 상어 쏘기로 뒤이은 유성우 전탄 격추.
- 대본 제안: 수정 마력을 쓰는 오린의 사전 방어, 수정의 위험한 마력 유출, 미라의 불완전한 방출과 점진적인 제어, 전투 직후의 탈진 연출. 대본 전체의 사용자 최종 승인을 뜻하지 않는다.
- 기존 세계관에 승인된 큰 사건을 반영했다. 각성의 영구성, 인물 생사, 잠식 해제와 흑막의 정체는 미정이다.
- [전체 열람본](index.html), [18페이지 선택 목록](selected-pages.json)을 작성했다. 휴대용 ZIP은 로컬 전달용이며 Git에는 포함하지 않는다.
- 첫 요격 시안과 초기 전체 작화는 art-v1/, 인물 상태 교정은 art-v2/에 보존했다. 사용자에게 탑·성벽이 작아지는 축척 오류를 지적받은 뒤 18페이지 전체를 art-v3-scale/로 교정했다. 현재 열람본은 selected-pages.json의 파일만 사용한다.
- 기존 작업값인 사람 1.7m·주탑 65m·외벽 10m·외벽 지름 100m를 프롬프트 기준으로 사용했다. 원경의 인물 크기를 줄이고, 근접 컷에서는 탑 기단과 넘어간 몸체를 화면 밖으로 잘랐다. 이 기록은 작화 검토이며 3D 실측 검증이나 사용자 최종 승인을 뜻하지 않는다.
- 교정 중 생긴 원경 입상 인물과 불필요한 문·통로를 제거하고, 초기 방어 구간의 동료들이 너무 일찍 쓰러진 표현도 수정했다. 정확한 생성·수정 지시는 prompts-v1/와 prompts-v3-scale/에 보관했다.
- [이미지 확인 기록](image-validation.json): 선택 이미지 18장의 존재, 1024×1536 크기, SHA-256을 확인했다. ZIP의 이미지 18장과 index.html 1개도 확인했다. 검토용 축소 모음은 review-01.jpg부터 review-03.jpg다.
- 한국어판 18페이지를 사이트 회차 목록과 독자 화면에 등록했다. 선택 원화와 무손실 WebP의 픽셀·해시 대응은 publication-ko.json에 기록했다. 영어판 이미지는 없어 한국어판만 등록하고 영어 주소에서는 기존 안내를 사용한다.
- 8화의 Vercel 정적 경로와 Nginx 기본 언어 리다이렉트를 추가했다. 원화·시안·프롬프트는 served asset에 포함하지 않는다.
- Graphify 실행 파일이 없어 그래프 갱신은 진행하지 못했다. 사용자 최종 작화 승인, PR 미리보기 확인과 운영 머지·배포는 서로 구분한다. 운영 머지·배포는 수행하지 않았다.
