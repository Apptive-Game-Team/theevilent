# 8화 작화와 독자 화면 검토 상태

2026-11-04 최신 구성 v5. 14페이지를 새로 작화했다. 각성과 상어 쏘기 반격은9화로 옮겼다.
사용자는 구성안을 승인했으며, 완성 작화 전체의 최종 승인을 뜻하지 않는다.

- 현재 기준: PLAN.md, CONTINUITY-v5.md, selected-pages.json. index.html은 이14장만 읽는다.
- 이전 화: 7화의 파손된 동문·파괴된 동쪽 포대·부상 청록 동료·성밖 핀의 다음 카드를 이어받았다.
- 전장: 적군은 동문 밖과 진입로, 방어군은 동쪽 안뜰, 정령은 남서 생활관 앞 피난처에 있다.
  붕괴 전경에서도 적군·시신·후방 생존자를 남겼다. 네 보루와 파란 박공지붕 생활관을 유지한다.
- 동선: 미라가 물결 궁수를 피난처로 옮기고, 붕괴 후 오린을 확인하러 갔다가 정령들에게 돌아온다.
  서문을 적으로 막지 않고, 부상자와 떨어지는 파편 때문에 즉시 이동할 수 없는 상황을 보여준다.
- 종족: 덩굴·바람·번개 정령과 물 부족의 물결 궁수·일반 슬라임·수룡을 구분한다.
  생성 중 발견한 사람형 피난민, 추가 문, 잘못된 부상 상태, 되살아난 주탑과 동료 거리 오류는 따로 수정했다.
- 전투: 방어 카드·지상 바람 공격·물 화살/물줄기·남은 포대와 번개 저항을 나눴다.
  이번 화에는 상어 쏘기, 수정 접촉, 각성, 유성 전탄 격추가 없다.
- 사망: 이름 없는 양측 전투원은 시신과 피로 표현한다. 오린·세 동료는 전투불능이나 생사는 미정이다.
  마지막에는 미라 뒤의 피난 정령들이 생존해 있으며 다음 유성우를 바라본다.
- 지침: story/AGENTS.md에서 필수 연속성 준비 절차로 연결했다. comic-authoring의 art-direction.md에
  이전 화 확인, 개체 목록, 고정 배치, 컷별 시야/거리/가림, 문제에 맞는 마법 선택, 실제 원고 대조를 명시했다.
- 보존: art-v1~v4와 PLAN-v4-superseded.md, selected-pages-v4-superseded.json은 이전 시안이다.
  새 원화와 수정 전 탐색은 art-v5/, 정확한 지시와 참고 목록은 prompts-v5/에 있다.
  휴대용 ZIP은 로컬 전달용이며 Git에 포함하지 않는다.
- 검증:14장 PNG 존재·1024×1536·서로 다른 SHA-256, ZIP14장+HTML1개 확인.
  무손실 WebP와 선택 원화의 픽셀/해시 대응·표지 해시 확인. npm run lint 통과.
  Playwright 전체82개 통과(빌드 포함): 데스크톱·320px 모바일, 목록→8화→14장 디코딩,
  읽기 진행·회차 이동·언어 안내·가로 넘침을 검사했다. 검사 후 표지 대체 텍스트만 실제 자르기에 맞췄다.
- 로컬 검토본은4198포트다. Vercel에서 해당 미리보기 프로젝트가 없어 호스팅 미리보기 검증은 없다.
  새 커밋의 CI 상태는 로컬 검사와 별도로 확인한다. 운영 머지·배포는 하지 않았다.
- Graphify 실행 파일이 없어 갱신하지 못했다. 구도와 치수 작업값은 작화의 실측 보증이 아니다.
