# 3화 원고

미라가 현장으로 날아가 잠식된 핀과 싸운 뒤, 오린의 리콜로 탑에 돌아오는 12장 원고다. 웹사이트 공개 경로에는 연결하지 않았다.

- [검토 화면](index.html): 브라우저에서 열어 선택된 12장을 순서대로 읽는다.
- [현재 선택](selected-pages.json): 이미지·프롬프트·대사·검수 상태의 기준이다.
- [구성](PLAN.md), [전투 설계](BATTLE-PROPOSAL.md), [검수 기록](REVIEW.md)
- [참고 기록](REFERENCES.md): 이전 회차와 로컬 원본의 역할을 기록한다. 과거 회차의 미채택 시안 전체를 이 PR에 포함하지는 않는다.

선택된 원고, 선택에 기록된 직전 수정본과 프롬프트를 보관한다. art-v1/·art-v2/의 모든 파일이 선택된 원고는 아니므로 selected-pages.json을 확인한다. 5장의 중간 수정본도 프롬프트의 수정 과정을 확인할 수 있도록 남겼다.

검토 화면을 다시 만들려면 Python 3와 Pillow가 필요하다. 이 디렉터리에서 실행한다.

```sh
python sync-production.py
python build-reader.py
```

두 스크립트는 현재 선택의 파일과 이미지 규격을 검사한다. sync-production.py는 선택을 예전 버전으로 바꾸지 않는다. 검수 완료 표시는 제작자의 점검 기록이며 사용자 최종 승인이나 게시 승인을 뜻하지 않는다.
