# 워드 대륙 지리 초안 v1

현재 비교용 수정본은 [word-continent-v2.png](word-continent-v2.png)이다.
기존 만화와 같은 굵은 선·큰 색면을 적용하고 초원의 개방감을 늘렸다.
정확한 생성 프롬프트는 [prompt-v2.txt](prompt-v2.txt)에 있다.

2026-10-29 사용자가 만화보다 대륙 지도를 먼저 잡자고 요청했다.
첫 페이지는 더 높은 시점에서 초원과 옆 산맥을 내려다보는 방향으로 조정한다.
인간 건축물은 마법 타워 하나만 둔다는 결정은 유지한다.

## 배치 제안

추가 방향: 하이랄 평원처럼 탁 트인 초원과 완만한 언덕, 옆의 산맥을 참고한다.
그림체는 기존 만화의 굵은 선과 큰 색면을 그대로 쓴다. 미세한 풀·잎·해안선
묘사를 줄이고 단순한 셀 명암으로 정리한다. 외부 작품의 지형을 복제하지 않는다.
첫 [지도 시안](word-continent-v1.png)은 비교용으로 보존하고 수정본은 별도 파일로 둔다.

- 중앙의 넓은 초원에 단독 마법 타워를 둔다.
- 세계수와 주변 숲은 타워의 북서쪽에 둔다.
- 산맥은 타워의 동쪽 초원에 인접하도록 두고, 그 산자락에 돌부족 서식지를 둔다.
- 타워에서 세계수 숲과 돌부족 서식지로 자연 길이 갈라진다.
- 돌부족 마을은 바위·돌무더기와 자연 공간이며 집이나 성채는 없다.

위 방향·해안선·강은 이번 지도 제작을 위한 제안이다. 대륙의 최종 지리나
실제 이동 거리·시간·축척이 확정된 것은 아니다. 불지옥은 별도 차원이므로
이 대륙의 땅이나 이웃 나라로 그리지 않는다. 고대 차원문의 위치도 공개 지도에
미리 표시하지 않는다.

## 현재 작업 순서

1. 이 지도에서 지형과 세 장소의 상대 위치를 조정한다.
2. 지도에 맞춰 1페이지의 위쪽 대륙 전경·아래쪽 마법 타워를 높은 시점으로 다시 잡는다.
3. 배경을 이어 맞춘 뒤 20페이지 만화를 이어 그린다.

20페이지 대본은 [PLAN.md](../../episodes/001/PLAN.md)에 유지한다.
지도 제작 중에는 나머지 만화 페이지를 추가 생성하지 않는다.
정확한 생성 프롬프트는 [prompt.txt](prompt.txt)에 보관한다.
