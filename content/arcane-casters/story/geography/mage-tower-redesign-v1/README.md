# 성벽으로 둘러싼 마법사의 탑 재설계 시안

2026-10-30 사용자 요청. 기존 페이지의 탑·지형 불일치 때문에 연속 원고 제작을 중단하고 배경 컨셉부터 재정립한다. 사루만의 아이센가드처럼 높은 중앙 탑을 넓은 성벽이 둘러싼 구조를 탐색한다. 기존 성벽 금지와 파란 원뿔 지붕 탑은 이 시안의 제약이 아니다. 사용자 최종 승인 전 시안이며 1~4화나 기존 원고를 자동 교체하지 않는다.

## 공간 제안

- 중앙: 하나의 높은 마법 연구 탑.
- 둘레: 원형 성벽, 넓은 안뜰, 낮은 네 모서리 보루.
- 남쪽: 전투용 큰 정문과 그 앞의 열린 전장.
- 북쪽: 대피용 작은 후문과 안뜰의 대피 집결 공간.
- 탑 현관: 남향. 대포와 돌 골렘을 배치할 공간은 안뜰 남쪽과 정문 바깥.
- 서쪽: 성벽 밖 자연 개울. 해자·다리·절벽 위 요새가 아니다.

색상·치수·정확한 평면과 지리 방향은 연속성 검토용 제안이며 아직 확정하지 않는다. 조감도·정면·배치도의 동일 건물 여부를 먼저 검수한다. 세부 지역 지형과 전투 배치도는 이 탑 후보를 기준으로 다음 단계에서 제작한다.

## 상태

현재 기준은 [tower-design-v2-residences.png](tower-design-v2-residences.png)이다. 사용자가 성벽 안 생활관을 요청했고 이 디자인을 기반으로 이전 만화 장면을 수정하도록 지시했다. 중앙 탑·원형 성벽·앞 정문·뒤 대피문과 안쪽 생활관 네 동을 조감도·정면·배치도에서 유지한다. 기존 5~7화 초안의 추가 페이지 생성은 중단하며, 새 설정화와 전장 구도부터 정립한 뒤 기존 장면을 수정한다.
